## YT-001 · Claude Code HTML page into GoHighLevel
Priority. Added 25 Oct 2026, from that night's AI Daily (GitHub trending).

**Working title:** How to get Claude Code to design clean, anti-AI-slop HTML landing pages and deploy them straight into GoHighLevel via the GHL CLI (end-to-end build).

**Angle:** Marketers and owners who build landing pages in Claude keep getting the same purple-gradient page, then rebuild it by hand in the GoHighLevel builder. Promise: one design skill, one HTML file, that file in GoHighLevel. Emotion: WOW + FINALLY.

**Pillar:** 2 How to (primary). The pillars file says a video belongs to exactly one. This one is a how-to: one job, follow the steps, end with a page in GoHighLevel. The build on camera is the proof, so it uses pillar 1 material. Filter: yes. Claude Code and GoHighLevel.

**Story type:** `current`. **ARR:** Authority (the two repos also make the open a Reach moment). **Lane:** Value. **Mix:** Adjacent. The shape is the build-first screen share this engine already uses. The subject is tonight's repos plus the CLI. **Momentum:** tease until it's recorded, then shout. **Source story:** none. Source is the newsletter and the two repos.

**Format:** Build-first screen share. End to end: install the anti-slop HTML skill in Claude Code, generate one landing page as HTML, put that file in GoHighLevel with the GHL CLI.

**Sources (credit both in the description):**
- `pbakaus/impeccable`: https://github.com/pbakaus/impeccable. Design language skill pack for AI coding harnesses. 86k+ stars in AI Daily, 25 Oct 2026. Apache-2.0. Site: https://impeccable.style
- `Nutlope/hallmark`: https://github.com/Nutlope/hallmark. Anti-AI-slop HTML skill for Claude Code plus Cursor and Codex. Made by Together AI. MIT. Site: https://www.usehallmark.com

**Why Hallmark is the one I build with:** Impeccable is the design language (the named tells, the `/impeccable` commands). Hallmark returns one self-contained HTML file. That is the file GoHighLevel can take. One job in this video: Hallmark. Impeccable gets a credit and a ten-second look.

**Guardrails:** demo page only. No Systemise and Scale client, no internal plan, no side-business frame. Blur the API token and the location id. No invented page stats. Hallmark asks for real photos and real numbers: if I don't have one, I say so. No "DM me".

**Beat 3. The two repos (short).**
On screen: both GitHub pages.
Impeccable: design language for the coding harness. 86k+ stars in the 25 Oct AI Daily. Install, if I ever show it, is `npx impeccable install` from the project, then `/impeccable init`. Claude Code plugin: `/plugin marketplace add pbakaus/impeccable`. Credit only, in this video.
Hallmark: the HTML skill. One file out. That's the file for GHL. Credit Nutlope and Together AI.

**Beat 4. Install Hallmark. Pick one path on the dry run and say only that path.**
Claude Code only, from the terminal:
`npx skills add nutlope/hallmark -g --agent claude-code`
Node 18 or later. The browser check also wants `npm i -g puppeteer-core` and Chrome. Without them the static checks still run.
Or, inside Claude Code:
`/plugin marketplace add nutlope/hallmark`
then `/plugin install hallmark@hallmark` (call it as `/hallmark:hallmark`).
Reload. Type `/` and show `hallmark` in the list before moving on.

**Beat 5. Same brief, with the skill.**
`/hallmark` then the brief. Use a demo I can say in public:

```
A landing page for [one offer, one sentence].
The visitor should [book a call / read / buy].
Use only these facts: [real facts, or "no numbers"].
One page. Self-contained HTML.
```

It will ask for photos and numbers. Give it real ones or say I don't have them. Don't let it invent a customer count.

**Beat 6. The file.**
Open the HTML. One file, CSS in the page. Put it next to `slop.html` if the thumbnail is hook 5.
Point at one tell that is gone. If the page is wrong, one rescue only: `/hallmark audit` reports, `/hallmark redesign` rebuilds and keeps the content. Then move on.

**Beat 7. Into GoHighLevel.**
On screen: the HTML file, then Claude Code, then the terminal. Secrets blurred.
Say: put this file in my GoHighLevel account with the GHL CLI. Leave the drag-and-drop builder alone.
Read the command it actually runs.
- Page live: open the URL, full screen, then flash `slop.html` beside it.
- Command never writes a page: say so. Upload the one HTML file instead. Sites, then WordPress, then Pages, then Upload New HTML Page. One `.html` file, 5 MB max, images on absolute URLs (Hallmark's Wikimedia photos already are). A later edit is Upload New Version, same URL. GHL won't edit the HTML in place.
