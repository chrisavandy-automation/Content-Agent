# YouTube engine
Platform-specific only: titles, thumbnails, scripts, video formats and the idea bank. Pillars, voice and stories come from `database/`.

## Format (Superpowers breakdown)
Build-first formats lead: screen shares, voiceover walkthroughs, written-to-video breakdowns. Grow into talking to camera. Don't start there.
- Hooks = title + thumbnail text + first 15 seconds.
- Thumbnails: 1280×720, few words, big type.
- A `youtube-hooks` skill is still to build (same lanes and database as `linkedin-hooks`). Until then, a video card holds 5 hooks: 4 proven + 1 wildcard, one of them `plain` (`database/writing/hooks.md`).
- Drafts: `engines/youtube/drafts/YYYY-MM-DD-slug.md`.
