I used to do all my ad work in Claude chats.
Now it runs in an app I built. Here's how it works:

I'm always working on ads.
Ideating angles, writing hooks, drafting scripts, going back and forth on all of it.

For a long time, all of that lived in chats.

But chats get long.
Context gets lost, and you end up scrolling up looking for the hook you liked an hour ago.

Spread that across a gazillion chats and it gets chaotic fast.

So I built my ad work its own operating system.

Here's what's in it:

> Ideation: angles first, then hooks, scripts and static concepts
> Libraries: winning ads, losing ads and competitor ads, all in one place
> A section for pushing approved copy, statics and videos into Meta
> A bird's-eye view of what every skill and routine costs me to run

That last one matters more than it sounds.
Every job in there has a price next to it now.

Under the hood, it's a few layers:
Skills for each job, memory so nothing gets lost between sessions, routines that run on their own, and the app sitting on top.

It's probably one of the coolest things I've built.

To be fair, there's still loads to do.
The UI needs work.
I'm still ironing everything out.

But I'm not going back to a gazillion chats.
