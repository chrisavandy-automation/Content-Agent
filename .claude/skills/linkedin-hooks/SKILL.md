# Hooks
Reads: `database/writing/virality.md` (lanes, levers, the flow), `database/writing/hooks.md` (types, checklist, my rules), `database/examples/hooks.md` and `database/examples/index.md` (proven hooks: filter by lane and type, best results first; quote only the 1-3 you borrow), `database/writing/anti-ai.md`.
Platform notes (fit above "see more"): `engines/linkedin/README.md`.

1. **Angle:** confirm in one line: idea · reader promise · target emotion · pillar. If any is fuzzy, fix it with me first.
2. **15 hooks: Value 5 · Emotion 5 · Story 5.** In each lane: 4 PROVEN (each names what it borrows: an example id or a hook type) + 1 WILDCARD (names the reference it breaks from). At least one `plain` hook in the set. Use only real details from the brain dump or Story Bank; a missing number stays a [bracket].
3. **Hook gate** (`database/writing/hooks.md`, "The hook gate"): callout + promise + the 5Cs + anti-AI (`python tools/slop_check.py` on the set, written to the scratchpad first) + true. Rewrite or drop every FAIL before showing anything. Never show a hook that fails.
4. **Show three short lists.** Each hook: the hook · callout ✓ and promise ✓ named in a few words · type · proven/wildcard (+ source) · weakest lever and the one move that would lift it. No scores, no winner picked for me. Lead with what's weak.
5. **I play:** pick, mix or rewrite. Run my pick through the gate too (say plainly if it fails and why). Offer 3 tight variations, each changing one lever (name it), all passing the gate.
6. Save the final hook to the top of `database/examples/hooks.md` (Mix, lane, Result: [after posting]) and to the Idea Bank row's Hook field if there is one.
Done when I've chosen a hook and it's saved.
