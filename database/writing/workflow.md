# Writing workflow (AI assists, I decide)
Read by: the write skill. Source: `sources/ai-assist-and-viral-formats-lesson.md`.
AI is here to help me find ideas, iterate faster and tidy up. It doesn't replace my voice or my judgement.

1. **Brain dump (me, by voice).** Messy is fine. Speaking keeps it in my voice. The skill asks 2-3 questions only if something essential is missing (the real moment, the number, what I actually did).
   - Check: flag any line that might be someone else's (from a post I read) and ask "yours or someone else's?" (LinkedIn-Agent lesson, 22 Oct).
2. **Shape (AI).** Turn the dump into 1-3 angles, each tagged with a pillar and story type, and say which one I think fits my audience and why. I pick one.
3. **Hooks.** `writing/virality.md` → the hook flow: 15 hooks, 3 lanes. I pick.
4. **Body.** The lane suggests a structure (`writing/structures.md`); offer one alternative structure for the same idea ("what if this was a list instead?"). Borrow the shape from a matching example in `examples/`, never the words.
5. **Tighten.** Edit to my voice (voice file: LinkedIn-Agent `shared/voice-profile.md` until it moves here). Run `tools/slop_check.py`, fix every hit, then show me.
6. **My final read.** I read it out loud and decide. The skill doesn't call a post "ready" on my behalf.
