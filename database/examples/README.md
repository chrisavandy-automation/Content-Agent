# Examples (post and video references)
The proven material the skills copy the SHAPE of, never the words. This is what makes the 70 in 70/20/10.

## How it's laid out
- `index.md`: one row per example. Skills read this first and filter on the tags; they open only the 2-3 example files that match.
- `<creator>.md`: the full posts for one creator, each under a `## <id>` heading with the same id as the index.

## How skills use it
- **Ideate:** for each idea, find 1-2 examples with the same pillar + story type. Show the example's hook and structure, and say what we borrow. 7 ideas follow an example (PROVEN), 2 borrow a shape from a different pillar or platform (ADJACENT), 1 matches nothing in the index (WILDCARD).
- **Write / hooks:** filter by hook + structure; pick the top results by engagement; borrow the shape, write in my voice.
- **My own posts go in too**, tagged the same way, once they've got results. Over time the best examples are mine.
- When a wildcard works, add it here: it becomes proven.
